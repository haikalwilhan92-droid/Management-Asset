# PROJECT: SIMPLE PERSONAL INVESTMENT TRACKER

Act as a professional full-stack developer and UI/UX designer.

Build a simple, lightweight, and responsive Personal Investment Tracker website.

The purpose of this application is to help me monitor my personal investment assets, total invested capital, current asset value, and overall profit/loss.

IMPORTANT:
This is NOT a complex financial management system.
Do not build unnecessary enterprise features, complicated accounting systems, or excessive analytics.

I want a simple personal dashboard that I can access approximately three times per week.

## 1. TECHNOLOGY STACK

Use:
- Next.js (App Router)
- TypeScript
- Tailwind CSS
- shadcn/ui
- Supabase for database storage
- Vercel for deployment
- Recharts for simple charts

Keep the application lightweight and easy to maintain.

## 2. CORE FEATURES

### A. Main Dashboard

Display:
- Total invested capital.
- Current total portfolio value.
- Total unrealized profit/loss.
- Overall ROI percentage.
- Asset allocation chart.
- List of owned investment assets.

All values must be calculated from actual saved data.

### B. Asset Management

Allow me to:
- Add a new investment asset.
- Edit asset information.
- Delete an asset.
- Record purchase quantity.
- Record purchase price.
- View average purchase price.
- View current market price.
- View current asset value.
- View unrealized profit/loss.

Support these asset categories:
- Cryptocurrency.
- Gold.
- Stocks.
- Mutual funds.
- Custom assets.

### C. Transaction History

Keep transaction management simple.

Allow me to record:
- Asset purchase.
- Asset sale.
- Transaction date.
- Quantity.
- Purchase or sale price.
- Transaction fees (optional).

Show transaction history in a simple table.

### D. Market Price Monitoring

Research and integrate free market data APIs.

Preferred sources:
- CoinGecko for cryptocurrency.
- GoldAPI.dev or another verified free source for gold.
- A reliable free source for Indonesian stock prices, if available.

Requirements:
- Retrieve current market prices.
- Convert prices to IDR.
- Display the last updated timestamp.
- Provide a manual refresh button.
- Use caching to reduce API calls.
- Do not invent or fabricate prices.
- If an API is unavailable, allow manual price input.

Important:
For gold, distinguish international spot prices from local gold retail and buyback prices.

For assets without a reliable free API, manual pricing is sufficient.

### E. Portfolio Overview

Show a simple table containing:

| Asset | Quantity | Average Buy Price | Current Price | Market Value | P/L |

Include a simple asset allocation chart.

## 3. FINANCIAL CALCULATIONS

Implement accurate but simple financial calculations.

Total Invested Capital:
Sum of remaining acquisition costs, including applicable purchase fees.

Current Market Value:
Current Asset Quantity × Current Market Price.

Unrealized Profit/Loss:
Current Market Value - Remaining Cost Basis.

ROI:
(Unrealized Profit/Loss / Remaining Cost Basis) × 100%.

Use weighted average cost for multiple purchases and partial sales.

Keep deposits and withdrawals separate from investment profits.

Use decimal-safe calculations for financial values.

## 4. DATABASE

Use Supabase PostgreSQL.

Create only the necessary tables:

- assets
- transactions
- price_history

Use proper relationships and timestamps.

Enable Row Level Security.

Use Supabase Authentication if needed for a private dashboard.

Do not store API keys in frontend code.
